# Research question to evidence map

Every claim of the thesis points to a test or an experiment that can be re-run. Commands run on a
normal machine (`pnpm setup:zk` is slow and exceeds the sandbox time limit).

The repository only fixes RQ4 and RQ5 by name (P6.3 analysis). The remaining rows are grouped by
mechanism. Put the RQ number from the proposal in the first column when finalising.

| RQ                           | Claim to support                                                     | Evidence (test or experiment)                                                                                                                                                                                                                | Command                                                 |
| ---------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| (issuer authenticity)        | Only credentials signed by a registered issuer are accepted          | `tests/zk/issuer-proof.test.ts`; `tests/chain/credential-verifier.test.ts` (unregistered issuer, other issuer swapped into signals); scenarios `credential-tampered`, `signature-other-issuer`, `signature-malformed`, `issuer-unregistered` | `pnpm test:zk`, `pnpm chain:test`, `pnpm experiment:p5` |
| (holder-key binding)         | A copy of a credential without the holder secret cannot be presented | `tests/zk/holder-proof.test.ts`; scenarios `holder-without-key`, `holder-secret-guessed`, `holder-secret-out-of-field`                                                                                                                       | `pnpm test:zk`, `pnpm experiment:p5`                    |
| (replay protection)          | A proof cannot be reused, relayed to another verifier, or relabelled | `tests/zk/replay-proof.test.ts`; `tests/security/replay-protection.test.ts`; scenarios `replay-same-proof`, `replay-relabelled-challenge`, `relay-to-other-verifier`, `wrong-verifier`, `challenge-expired`, `challenge-unknown`             | `pnpm test:security`, `pnpm experiment:p5`              |
| (privacy)                    | Only threshold, issuer, challenge and verifier are revealed          | Public signal list in `docs/protocol/protocol.md`; `tests/zk/proof-engine.test.ts`; holder key never printed in `tests/e2e/cli-flow.test.ts`                                                                                                 | `pnpm test:zk`, `pnpm test:e2e`                         |
| (attack resistance)          | The proposed model leaves no listed attack open; ablation shows gaps | `tests/security/attack-scenarios.test.ts` (fails if an attack is open in `full` or an unlisted gap appears); `experiments/scenarios/` output in `experiments/results/` (verification success rate, attack rejection rate)                    | `pnpm test:security`, `pnpm experiment:p5`              |
| RQ4 (performance cost)       | Prove time, verify time, proof size, memory, constraints and gas     | `experiments/benchmarks/`; `experiments/results/2026-11-22-081902/gas/p6-table.md` and `.csv`; no-gas run in `2026-11-22-081920/no-gas/`                                                                                                     | `pnpm experiment:p6`, `pnpm experiment:p6:nogas`        |
| RQ5 (cost of each mechanism) | Overhead added per step B1 -> B2 -> B3 -> B4 and versus baseline A   | `p6-overhead.csv` and the SVG charts next to it; `experiments/configurations/`                                                                                                                                                               | `pnpm experiment:p6:analyze`                            |
| (end to end)                 | The flow works through the CLI on a local chain                      | `tests/e2e/cli-flow.test.ts` (accept, replay exit code 2, refuses threshold above GPA)                                                                                                                                                       | `pnpm test:e2e`                                         |

Limits that qualify these claims are in [threats-to-validity.md](threats-to-validity.md).
